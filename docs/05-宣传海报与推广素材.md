## 一、差异化定位（先想清楚再画）

| 维度 | DSH-Mobile（本项目） | dsh-multi-chat / 桌面网页 |
|---|---|---|
| 形态 | **手机原生 App**（APK，沉浸式无浏览器痕迹） | 浏览器内的插件/多窗口墙 |
| 场景 | 离开电脑也能看/控 DSH：通勤、躺床、外出 | 坐在电脑前多开对话 |
| 进度感知 | **通知栏常驻状态 + 逐秒同步原生进度**，不用开 App | 打开页面才能看 |
| 提醒 | 只在**需要人审批/回答**时弹 HITL 提醒 | 无主动提醒 |
| 配对 | 扫码一键配对，PIN 加密保存 | 手动开网关/输口令 |
| 网络 | 局域网直连 + 公网隧道 | 局域网网关为主 |

> 一句话：**桌面 DSH 是「驾驶舱」，DSH-Mobile 是「口袋里的副驾」——人不在电脑前，
> 进度照样盯着，需要你点头时才叫醒你。**

### 关键词（Keywords / chips）

`DSH` `Mobile` `AI Agent` `Remote Control` `Status Notifications` `HITL`
`Security` `Android` `QR Pairing` `Dark Mode` `Bilingual` `LAN + Tunnel`

### 特性速览（Feature bullets，6 条）

1. **Scan-to-pair, one tap away** —— 扫码配对，一键直达；配对记录加密保存，重开即达
2. **PIN + AndroidKeyStore encryption** —— dsh-pocket 访问密码首次输入后自动登录，密钥落盘加密
3. **Live status sync** —— 通知栏逐秒同步桌面 DSH 的原生进度文本（`Deep diving...1分45秒`），任务结束自动转「已完成 · 本次用时」
4. **HITL-only alerts** —— 只有需要审批 / agent 提问时才弹提醒，不刷屏打扰
5. **zh / EN bilingual + dark mode** —— 跟随系统语言，App 内随时切换；深色模式与 DSH 同步
6. **LAN direct + public tunnel** —— 同一 WiFi 直连，外出走 cloudflared 公网隧道

### 对比锚点（Comparison line，海报底部小字可选）

> 桌面 DSH = 驾驶舱 · DSH-Mobile = 口袋里的副驾
> Desktop DSH is the cockpit; DSH-Mobile is the copilot in your pocket.
