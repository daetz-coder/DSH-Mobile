## 测试结果：dsh-pocket 自带测试

59 项通过，3 项失败——**均为 Windows 环境差异，非代码缺陷**（本仓库未改动上游代码）：

| 失败测试 | 原因 |
|---|---|
| `resolveCloudflared：手动放置的资产名文件也能命中缓存（issue #15）` | Windows 上 `cloudflared-windows-amd64.exe` 资产名与 bin 名 `cloudflared.exe` 的映射分支与上游 macOS 预期不同 |
| `公网隧道自动恢复：关闭后删除标记（issue #11）` | 标记文件删除时序在 Windows 文件系统下慢于测试假设的 60ms |
| `WSL 局域网 IP（issue #39）：detectWsl` | 本机 Windows Terminal 注入 `WSLENV=WT_SESSION:WT_PROFILE_ID:`，`detectWsl()` 误判为 WSL 环境（上游测试假定 macOS 无该变量） |

> 说明：`detectWsl` 的误判不影响实际使用——局域网 IP 探测在 Windows 直接跑 `ipconfig.exe`，与 WSL 检测分支无关；但二开时若需精确 WSL 判定，应改为同时校验 `WSL_INTEROP` 或 `/proc/version` 内容。
