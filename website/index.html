DSH-Mobile

把 DeepSeek Harness 装进口袋
Pair once by QR code — then watch and control your desktop DeepSeek Harness from your phone, anywhere.

Android 8+ · scan-to-pair · LAN + public tunnel

✦ 特性

📷 扫码配对

扫电脑 DSH 的二维码即连，配对记录加密保存，重开即达。

🔐 PIN 自动登录

首次输入 8 位访问密码自动加密保存，之后免输。

🖥️ 官方界面整页呈现

以 top-level 页加载，非 iframe，与桌面体验一致。

🔔 常驻状态通知

逐秒同步桌面原生进度文本，任务结束自动转「已完成」。

🌐 局域网 + 公网

同一 WiFi 直连，外出走 cloudflared 快速隧道。

🌙 深色模式 + 双语

跟随 DSH 主题，App 内 zh/en 随时切换。

📸 运行效果

🚀 快速开始

步骤说明
1. 电脑端安装两个服务端插件（dsh-pocket、dsh-web-mobile），然后 npx @deepseek-ai/dsh web
2. 手机端下载 APK 并安装（上方按钮）
3. 配对打开 App → 扫码 → 输入一次 8 位 PIN → 完成 🎉

插件市场：dshmarket.com · 推荐版本：dsh-pocket v1.13.4 · dsh-web-mobile v2.1.1（已测试，无需其他扩展）

🔒 安全

DSH 能在你电脑上执行代码——配对 URL / PIN / 会话 cookie 就是钥匙， 不要分享、不要提交到公开地方。PIN 存在电脑端，手机只持有加密配对记录。
